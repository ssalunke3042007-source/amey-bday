AMEY BIRTHDAY WEBSITE
======================

This folder contains a self-contained mobile-friendly birthday website.

Files:
- index.html
- photo1.jpeg
- photo2.jpeg
- photo3.jpeg
- photo4.jpeg

QUICKEST WAY TO GET A SHAREABLE LINK:
1. Create/sign in to a GitHub account.
2. Create a NEW PUBLIC repository, e.g. "amey-birthday".
3. Upload ALL FIVE files from this folder to the repository root.
4. In the repository open Settings -> Pages.
5. Under "Build and deployment", choose "Deploy from a branch".
6. Select "main" and "/ (root)", then Save.
7. Wait a minute or two. GitHub will show your website URL.
8. Send that URL to Amey on WhatsApp.

IMPORTANT:
- Keep the four photo files in the same folder as index.html.
- Do not rename the photo files unless you also change their names in index.html.
- The website is designed for mobile Safari and Chrome.
